# 🏘️ Euro Estates Dashboard

## 🧩 Overview

The **Euro Estates Dashboard** is an interactive **Power BI report** designed to analyze the **European real estate market** by providing insights into **property sales, rentals, pricing, property distribution, and amenities** across multiple European countries.

The dashboard enables users to explore market trends through dynamic filters, compare **rental and sales performance**, evaluate **property categories**, and understand how **property characteristics and amenities influence pricing**.

It also provides detailed portfolio statistics, property distribution, furnishing insights, and country-wise analysis to support better real estate decision-making.

# 🚀 Key Features

✅ **Interactive Filters**
- Filter data by **Year**, **Listing Type**, **Property Age**, and **Amenity Status**.

✅ **Portfolio Overview**
- Monitor total properties, rentals, sales, average rent, average sales price, and average market duration.

✅ **Property Type Analysis**
- Compare **Median Sales Price** and **Median Rent** across different property categories.

✅ **Rental vs Sales Distribution**
- Analyze the distribution of rental and sale listings by property category and year.

✅ **Country-wise Property Matrix**
- Explore property distribution across multiple European countries.

✅ **Pricing Insights**
- Compare **Average vs Median** prices to identify pricing skewness.

✅ **Amenity Impact Analysis**
- Evaluate how amenities affect rental pricing across property types.

✅ **Property Characteristics**
- Analyze furnishing status, parking availability, elevators, pools, gyms, and other property features.

# 📅 Dashboard Sections

## 1️⃣ Portfolio Overview

The top section provides a quick snapshot of the overall real estate portfolio.

It includes:

- 🏠 Total Properties
- 📈 Total Rentals
- 💰 Total Sales
- 💶 Average Rent
- 🏡 Average Sales Price
- ⏳ Average Days on Market

Each KPI card also displays supporting statistics such as:

- Portfolio contribution
- Median values
- Trend indicators

---

## 2️⃣ Property Type Price Analysis

A combined **Column & Line Chart** compares:

- **Median Sales Price**
- **Median Rent**

across property categories such as:

- Apartment
- Villa
- Office
- Retail
- Townhouse
- Mixed-Use
- Warehouse

This visualization helps identify:

- High-value property categories
- Rental demand
- Price differences across property types

---

## 3️⃣ Average vs Median Analysis

This section compares:

### Monthly Rent

- Average Rent
- Median Rent
- Pricing Skew

### Sale Price

- Average Sale Price
- Median Sale Price
- Distribution Skew

The skew analysis helps identify whether pricing is affected by premium properties or outliers.

---

## 4️⃣ Amenity Price Impact

This visual compares rental prices for properties:

- ✅ With Amenities
- ❌ Without Amenities

across different property categories.

It highlights the effect of amenities on rental pricing and helps understand value-added property features.

---

## 5️⃣ Rental Trends by Year

Analyze rental listings across different years based on:

- Properties with Amenities
- Properties without Amenities

This helps identify long-term rental trends and changing market preferences.

# 📊 Metrics Tracked

| Metric | Description |
|------|-------------|
| **Properties** | Total number of properties in the portfolio |
| **Rentals** | Total rental listings |
| **Sales** | Total sales listings |
| **Average Rent** | Average monthly rental price |
| **Median Rent** | Median monthly rental price |
| **Average Sales Price** | Average property sale price |
| **Median Sales Price** | Median property sale price |
| **Days on Market** | Average duration before a property is sold or rented |
| **Amenity Impact** | Rental price comparison based on amenities |
| **Pricing Skew** | Difference between average and median values |
| **Furnishing Status** | Distribution of furnished and unfurnished properties |

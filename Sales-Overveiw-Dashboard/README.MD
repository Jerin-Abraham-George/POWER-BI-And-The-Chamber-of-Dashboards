# 📊 Sales Overview Dashboard | Power BI

## 🧩 Overview

The **Sales Overview Dashboard** is an interactive **Power BI report** designed to analyze and monitor sales performance across different **regions, states, and time periods**.  

It provides a **comprehensive view of Sales, Profit, and Quantity (Qty)** with dynamic filters, enabling stakeholders to easily track **year-over-year (YoY) performance**, identify **regional trends**, and uncover **key business insights**.

The dashboard allows users to switch between **Sales, Profit, and Quantity metrics** while dynamically updating all visuals for deeper analysis.

---

# 🚀 Key Features

✅ **Dynamic Metric Selection**
- Switch between **Sales**, **Profit**, and **Quantity** with interactive buttons.

✅ **Year Filter**
- Analyze performance for **2021 – 2024** using slicer buttons.

✅ **Regional Performance Overview**
- Breakdown of metrics across **Central, East, South, and West** regions.

✅ **Monthly Trend Analysis**
- Mini bar charts display **monthly performance trends** for each region.

✅ **Geographical Insights**
- Interactive **map visualization** showing sales distribution by **state**.

✅ **Year-over-Year (YoY) Analysis**
- Compare **Current Year (CY)** vs **Previous Year (PY)** metrics.

✅ **State-Level Performance Ranking**
- Identify top-performing states based on selected metrics.

---

# 📅 Dashboard Sections

## 1️⃣ Regional Performance Cards

Displays performance metrics for four regions:

- 🟡 **Central**
- 🔵 **East**
- 🟢 **South**
- 🟣 **West**

Each card includes:
- Current metric value (Sales / Profit / Qty)
- Previous Year (PY) comparison
- Monthly performance trend chart

This allows quick identification of **regional growth or decline**.

---

## 2️⃣ Sales by State Map

An interactive **map visualization** displaying sales performance across states.

Features:
- Bubble size represents **magnitude of performance**
- Color-coded regions
- Tooltip showing:
  - State/Province
  - Region
  - Quantity or selected metric

This helps quickly identify **high-performing geographical areas**.

---

## 3️⃣ State Performance Ranking

A **ranked bar chart** displaying top-performing states based on the selected metric.

Users can easily identify:
- Highest sales states
- Profit leaders
- Regions with strong order volume

---

## 4️⃣ Current Year vs Previous Year Analysis

A detailed comparison table showing:

| Metric | Description |
|------|------|
| **CY Sales** | Current year sales |
| **PY Sales** | Previous year sales |
| **YoY Sales** | Year-over-year sales growth |
| **CY Profit** | Current year profit |
| **PY Profit** | Previous year profit |
| **YoY Profit** | Profit growth rate |
| **CY Qty** | Current year quantity sold |
| **PY Qty** | Previous year quantity |
| **YoY Qty** | Quantity growth |

The table helps analyze **performance trends across regions**.

---

# 📊 Metrics Tracked

| Metric | Description |
|------|-------------|
| **Sales** | Total revenue generated from orders |
| **Profit** | Net profit earned after deducting costs |
| **Quantity (Qty)** | Number of units sold |
| **YoY Growth** | Percentage change between current year and previous year |
| **PY Metrics** | Performance data from the previous year |

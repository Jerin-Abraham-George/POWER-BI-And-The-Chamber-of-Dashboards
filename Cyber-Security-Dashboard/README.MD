# 🔐 Cyber Security Dashboard

## 🌟 Overview
The **Cyber Security Dashboard** is an interactive Power BI solution designed to monitor and analyze cybersecurity incidents, response efficiency, breach trends, attack sources, and infrastructure health.

This dashboard provides security teams, SOC analysts, and decision-makers with real-time visibility into critical cybersecurity KPIs, helping organizations proactively identify risks, improve response times, and strengthen overall security posture.

## ⚙️ Features

- **Incident Monitoring**: Track total security incidents and yearly trend comparisons.
- **Response Time Analysis**: Analyze average incident response times across months.
- **Data Breach Tracking**: Monitor breach counts and identify improvements over previous years.
- **Firewall Uptime Monitoring**: Evaluate infrastructure reliability and operational continuity.
- **Patch Compliance Analysis**: Measure quarterly patch rate improvements.
- **Severity-Based Incident Classification**: Categorize incidents by Low, Medium, High, and Critical severity levels.
- **Attack Source Intelligence**:
  - Country-wise attack origin analysis.
  - Region-wise attack distribution insights.
- **Top Attack Type Identification**: Understand dominant cyber threats such as phishing, malware, and zero-day exploits.
- **Interactive Filtering**:
  - Risk Level
  - Attack Category
  - Department
